*Dataset = largest table ≥ 50 rows × 3 columns, or ≥ 1,000 rows; PDF/Word tables count only as numeric grids; peer-review files, reporting summaries and figures excluded. Largest table: 152,683 rows. Hand check of 105 machine decisions (verdicts published): 60/60 "dataset" calls were real data tables; every miss was a table under 50 rows. About half of rescued tables are primary measurements, half derived results. Filter check on 500 random population papers: 15% reference a repository somewhere; 13.5% of spreadsheet papers already have a Figshare identifier. Netting those out: roughly 2,800 to 3,900 papers, 8,000 to 11,000 buried dataset files.
