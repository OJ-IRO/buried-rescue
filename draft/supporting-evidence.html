4. Rescued tables put back to work

  • Two rescued TCGA-derived glioma tables joined by patient ID: 244 shared patients agree on survival, IDH and age in >96%; pooled 1,037 reproduce the known IDH survival split (validation only); plus the 121-patient hospital cohort (demo/).
  • ~4,400 patient records in verified patient-level tables, ~500 from institutional cohorts not in TCGA, GEO or dbGaP. All 462 rescued datasets written to a source file in the Index of NCI Studies' exact 27-column schema (deliverable/); 8 packaged with DataCite metadata.

5. Code, data, site (open, MIT)

  • Checked: BioStudies, publisher Figshare deposits (BMC, PLOS → NLM Dataset Catalog), NLM FAIR-SMART. None decides dataset-vs-not by content, none is funder-scoped, none reaches NCI's index. Mechanisms (26,228 papers): R01 43% · P30 47% · cooperative 19% · training 18% · SPORE 9%.
  • Repository: github.com/OJ-IRO/attachment-rescue — code, raw census, results, verdicts, packages, INS source file.
  • Working tool: attachment-rescue.vercel.app/app — search all 15,458 buried spreadsheets, filter by year/journal/license, look up any PMC ID, open the file. Evidence page: attachment-rescue.vercel.app
