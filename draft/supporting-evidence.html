About half primary measurements, half derived results. Filter check on 500 random papers: 15% reference a repository somewhere; 13.5% of spreadsheet papers already have a Figshare identifier. Net estimate: 2,800–3,900 papers, 8,000–11,000 buried dataset files.

4. Rescued tables put back to work

  • Two rescued TCGA-derived glioma tables joined by patient ID: 244 shared patients agree on survival, IDH and age in >96%; pooled 1,037 patients reproduce the known IDH survival split (median 88 vs 15 months; validation only). A third rescued table is a 121-patient hospital cohort not found in any catalogue (demo/).
  • Verified patient-level tables in the four samples: ~4,400 patient records, ~500 from institutional cohorts not found in TCGA, GEO, dbGaP or any catalogue. 8 datasets packaged with DataCite metadata (not uploaded). All 462 rescued datasets written to a source file in the Index of NCI Studies' exact 27-column curated-source schema (deliverable/).
